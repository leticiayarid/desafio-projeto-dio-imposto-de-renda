🦁 Lion Informe - Organizador para Declaração de Imposto de Renda
📖 Descrição

Projeto desenvolvido durante o desafio da DIO com o objetivo de criar uma ferramenta em Excel para auxiliar na organização das informações necessárias para a declaração do Imposto de Renda.

A solução foi criada utilizando recursos nativos do Excel, com foco em praticidade, validações de dados e navegação intuitiva entre as abas.

🎯 Objetivos do Projeto
Centralizar informações para declaração do Imposto de Renda;
Facilitar o preenchimento dos dados do contribuinte;
Organizar informações de dependentes;
Registrar informes bancários;
Controlar receitas e entradas financeiras;
Aplicar validações e melhorias de usabilidade no Excel.
